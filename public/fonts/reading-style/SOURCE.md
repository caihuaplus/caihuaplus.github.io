# Reading preview fonts

The font files and font-face definitions are from Retypeset commit `a636b6d393be714cab52d3fc4baddd3f3905f701`:
https://github.com/radishzzz/astro-theme-retypeset

- Early Summer Serif by GuiWonder: https://github.com/GuiWonder/EarlySummerSerif — SIL Open Font License 1.1 (`OFL-EarlySummer.txt`).
- STIX Two Text by The STIX Fonts Project Authors: https://github.com/stipub/stixfonts — SIL Open Font License 1.1 (`OFL-STIX.txt`).
- Font-face CSS from Retypeset: MIT (`LICENSE-RETYPESET.txt`).

Snell font files are omitted because their redistributable license was not established. These fonts are used only by the fictional Serif preview pending a final design decision.
